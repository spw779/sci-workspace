## Directory Map

| 路径 | 放置内容 |
| --- | --- |
| `01_reference/` | 文献 PDF、阅读材料和已有引用库导出 |
| `02_manuscript/` | 完整稿件；首次实际生成后可使用 `manuscript.docx` |
| `03_chapter/` | 分章节稿件，章节子目录按实际论文需要创建 |
| `04_data/` | 实验数据、原始照片、原始记录和数据说明 |
| `05_results/` | 分析输出、结果表、稿件图及可编辑来源 |

已有项目采用其他路径时，在本表登记实际对应关系；无需为符合模板搬移或重命名文件。

## Optional Subdirectories

以下是可选分类，是否已经创建以实际目录为准：

| 父目录 | 按需增加的子目录 |
| --- | --- |
| `03_chapter/` | `Abstract`、`Introduction`、`Methods`、`Results`、`Discussion`、`Conclusions` 或本稿实际需要的其他章节 |
| `04_data/` | `raw`：原始输入；`processed`：处理后数据；`metadata`：样本、分组、单位、方法记录及数据说明 |
| `05_results/` | `statistics`：统计输出；`tables`：结果表；`figures`：稿件图 |

Methods、Results、Conclusions 等章节根据实际论文需要增加，不强制一次创建。`03_chapter/Results` 用于结果章节正文，`05_results` 用于支撑正文的结果材料。归档、补充材料、投稿文件及分析脚本需要时再设目录。

## File Conventions

- 保留现有文件名和文稿格式。新文献可沿用 `Year-Title.pdf`；新章节稿可沿用 `<Section>_vN.docx`。具体版本管理由写作任务处理。
- 原始输入保留不改，清洗数据和分析输出另存；这是工作约定，不代表文件已被系统设为只读。
- 原始照片属于数据；排版后的稿件图片属于结果。文件夹名称不能证明材料已核验或已被稿件采用。
- 大型数据或独立分析项目可登记外部路径及版本，默认不复制整个项目。
- 初始化只搭建结构；实际写作、文献处理和分析由相应 skills 完成，相关索引及记录按需建立。
