# 论文工作区

开始任务前读取论文根目录的 `WORKSPACE_GUIDE.md`。未指定根目录且从子目录接续时，向上查找最近的指南并核对项目位置。

- 保留已有文件与手写说明；原始输入保留，处理结果另存。
- 核对指南中选用的稿件是否存在；本轮输入遵循用户指定和已核实记录，最大编号用于确定新文件名。
- 分别保存整稿和章节的新版本，保留旧版。实际写作后更新当前稿件和下一步，合稿时记录使用的章节版本；仅检查时保持只读。
- 再次合稿前核对整稿中的独立修改，避免旧章节覆盖新内容。
- 用 `sci-workspace` 搭建和检查目录，按任务使用对应的写作、文献或分析能力。
- 自定义布局按指南记录的实际路径检查和补缺，标准目录缺失报告不作为另建目录的依据。
- 在项目指南中记录已知事实和文件位置，未知信息保持待补充。
